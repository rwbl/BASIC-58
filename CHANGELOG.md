### Project Status
The interpreter has a substantial set of working BASIC features.
* Variables, expressions, functions, loops and branching are implemented.
* INPUT, DATA/READ, error handling and file operations work.
* BREAK is implemented.
* Completed a broad set of regression tests.

The language and implementation are still evolving, and the project hasn't reached a stable release.
